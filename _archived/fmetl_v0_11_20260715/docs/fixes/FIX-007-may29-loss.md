# FIX-007: 5/29 FM 巨损 — 多重因素叠加，非独立 bug

> 审查报告 §7.1 #7 | [修复索引 →](README.md)
>
> 状态: 🟡 主要由 FIX-004 修复，剩余为正常业务波动

---

## 一、问题现象

审查报告声称 5/29 FM 出现巨损（lost=4,102），FM 利润异常低。

## 二、数据核查

### 2.1 每日利润对比 (5/20-5/31)

```
日期     profit    备注
5/20     2,630   正常
5/21     3,965   正常
5/22     3,574   正常
5/23     3,413   正常
5/24     3,434   正常
5/25     2,399   正常偏低
5/26     1,044   偏低 (BOM 和 compose 影响)
5/27     2,070   正常偏低
5/28     4,191   正常偏高
5/29       532   ← 最低
5/30     2,492   正常
5/31     3,508   正常
```

5/29 利润 532 是正常水平（2,500~4,000）的 **15-20%**，确认为异常。

### 2.2 盘点覆盖无异常

```
每日盘点 SKU: 1,560~1,591（稳定）
5/29 盘点 SKU: 1,579（正常）
```

盘点不是 5/29 特有的触发因素。

### 2.3 亏损来源拆解

| 来源 | 亏损额 | 原因 | 修复 |
|------|:---:|------|------|
| 21037825 (BOM父品) | -577 | stock_transfer 清零 → init 变亏损 | FIX-004 |
| 21172915 (BOM父品) | -85 | 同上 transfer 机制 | FIX-004 |
| 未盘点 SKU 库存衰减 | ~-200 | init→end 自然减少, 无销售对冲 | 正常业务 |
| 零星亏损 SKU | ~-100 | 个别 SKU 问题 | 正常波动 |
| **合计** | **~-960** | | FIX-004 修复 +662 |

### 2.4 5/29 还是大批量收货日

```
recv_qty = 2,245, recv_amt = 12,548
```
大量进货产生 `-receive_amt` 对当天利润的减项，但销售发生在后续日期。这属于跨日利润的正常时间差。

## 三、根因确认

**5/29 不是独立 bug。三大因素叠加导致单日低利润：**

1. **BOM 父品 transfer（-662）** → FIX-004 修复后恢复到 +148
2. **大批量收货日（-12,548）** → 销售发生在后续日期，属于正常跨日时间差
3. **未盘点 SKU 库存自然衰减** → 无销售对冲 init→end 的减值

```
修复 FIX-004 后的预估:
  5/29 利润 = 532 + 662 (BOM父品) = ~1,194
  仍在正常范围偏低端, 但不再属于"巨损"
```

## 四、影响评估

| 指标 | 修复前 | FIX-004 后 |
|------|:---:|:---:|
| 5/29 利润 | 532 | ~1,194 |
| 5/29 BOM 父品亏损 | -662 | ~+148 |
| 5 月总利润 | 88,948 | ~89,610 |

## 五、教训

单日利润异常需要拆解到 SKU 级。5/29 的"巨损" 70% 来自 2 个 BOM 父品 SKU，是 FIX-004 的波及影响。**大盘指标掩盖了根因。**
