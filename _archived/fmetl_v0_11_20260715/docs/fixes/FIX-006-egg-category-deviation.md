## 一、问题现象

31 天全月数据：FM 蛋类利润 2,246 vs QDM 3,448，差异 -1,202 (-34.9%)。销售额完全一致，差异全部来自成本侧。

## 二、根因分析

### 2.1 问题集中在两个 BOM 相关 SKU

| SKU | 名称 | 角色 | 销售额 | 利润 | 问题 |
|-----|------|------|:---:|:---:|------|
| 21037825 | 杂粮鲜鸡蛋30枚 | BOM **父品** | 726 | **-552** | stock_transfer_out=724 未补偿 |
| 20669362 | 鲜鸡蛋15枚 | BOM **子品** | 240 | **-478** | 承接 transfer + unknow_lost 波动 |

```
蛋类 8 个 SKU
│
├── 6 个正常 SKU: sale=22,280  profit=+3,276  ✅ 毛利率 14.7%
│
└── BOM 父子对 (21037825 + 20669362):
    sale=966  profit=-1,030  ← 拖累蛋类 1,202 元偏差
    
    QDM 蛋类: 3,448
    FM 去 BOM 对: 3,276  → 差异 -172 (-5.0%) ✅ 已在目标范围内!
```

### 2.2 21037825 逐日追踪

```
日期     sale  receive  bom_out  xfer_out  init_a  end_a   profit
5/24       5     403        0         0         0    319     +16
5/25       8     805        0         0       319    990     +25
5/26      14       0        0         0       990    755     +44
5/27       7       0        0         0       755    638     +22
5/28       1       0      5/0*        0       638    577     -51  ← bom_out_amt=0!
5/29       0     228      228       724       577      0    -577  ← TRANSFER DAY
5/31       2     456        0         0         0    386     -30

*5/28: bom_out_qty=5 but bom_out_amt=0 (源表 inbound_amount=0)
```

5/29 是关键日：sale=0，但 `bom_out(228) + stock_transfer_out(724)` 双重扣减，profit = 0 - 228 + 228 + 0 - 577 = **-577**。

**非 5/29 的 6 天合计 profit = +26。5/29 单日拖垮全局。**

### 2.3 父子传导链

```
5/29:
  父品 21037825 (杂粮鲜鸡蛋30枚)
    init=42件×13.73=576.62
    receive=12件×19.00=228.00
    bom_out=12件×19.00=228.00  (BOM分配)
    eq = 42 → end=42件×17.25=724.39
    → stock_transfer触发! end→0, xfer_out=724.39
    profit = -576.62  ← init_stock 纯亏损!
    │
    │  transfer 42件×724.39
    ▼
  子品 20669362 (鲜鸡蛋15枚)
    bom_in += 42件×724.39  (transfer承接)
    end_stock += 42件×724.39
    → 后续日期 unknow_lost 剧烈波动 (-268~+352)
    → 子品 profit = -478
```

### 2.4 根因确认

蛋类偏差的根因是 **FIX-004 BOM 父品库存转移负毛利**：
- 父品 transfer 清零 end_stock 但不补偿 bom_out → profit = -init_stock
- 子品承接 transfer + bom_in → 无法销售的部分变成 unknow_lost
- 父子两头挤压利润 -1,030 元

**这不是蛋类特有的问题，而是 BOM 机制缺陷在蛋类这个品类上的表现。**

## 三、修复

### 3.1 主要修复: FIX-004

修复 stock.py 中 BOM 父品 transfer 时增加 `bom_out_amt` += transfer_amt。

修复后 21037825 5/29 利润变化：
```
修改前: bom_out=228, end=0, profit = 0 - 228 + 228 + 0 - 577 = -577
修改后: bom_out=228+724=952, end=0, profit = 0 - 228 + 952 + 0 - 577 = +147
```

21037825 全月利润：-552 → **+173**

### 3.2 次要修复: 子品 unknow_lost 改善

父品 transfer 修复后，子品不再承接无销售能力的 transfer 库存，unknow_lost 波动自然减小。

### 3.3 剩余偏差

修复后蛋类预估利润 ≈ 3,276（正常SKU）+ 173（父品修复）+ ~0（子品改善）= **~3,450** vs QDM 3,448

偏差收窄至 ~0%，进入 ±5% 目标范围。

品类级别的偏差分析需要逐 SKU 拆解。蛋类 8 个 SKU 中 6 个表现正常（+3,276 vs QDM 3,448 = -5%），整体 -34.9% 偏差完全由 2 个 BOM 相关 SKU 造成。**品类平均掩盖了 SKU 级异常。**
