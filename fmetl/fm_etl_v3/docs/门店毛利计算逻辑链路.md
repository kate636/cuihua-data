# 门店毛利计算完整逻辑链路（业务视角）

> **前提**：抛开现有 ETL 代码，从业务本质重新思考

---

## 一、核心公式

### 1.1 门店毛利公式（库存方程）

```
门店毛利 = 销售额 - (进货额 + 加工入额 - 加工出额) + (期末库存额 - 期初库存额) - 损耗额
```

**展开**：
```
门店毛利 = 销售额 - 进货额 - 加工入额 + 加工出额 + 期末库存额 - 期初库存额 - 已知损耗额 - 未知损耗额
```

### 1.2 库存恒等式

```
期末数量 = 期初数量 + 进货数量 + 加工入数量 - 加工出数量 - 销售数量 - 已知损耗数量 - 未知损耗数量
```

### 1.3 金额计算通式

```
金额 = 数量 × 单位成本
```

**关键发现**：
> **所有金额计算（进货、加工、库存、损耗）都依赖同一个核心参数：单位成本**

## 二、单位成本的来源

### 2.1 核心问题

**单位成本从哪里来？**

这是整个链路的起点。根据商品类型不同，来源不同：

### 2.2 商品分类

| 类型 | 定义 | 单位成本来源 |
|---|---|---|
| **标品** | 验收条码 = 销售条码（不拆分） | 直接取成本价池 / 进货均价 |
| **BOM 商品** | 验收条码 ≠ 销售条码（需拆分） | parent 成本价 × 分摊比例 |

### 2.3 标品单位成本链路

```
标品单位成本来源优先级：
  ① 成本价池（表 9）：cost_price
  ② 进货均价（表 2）：avg_inbound_price  
  ③ SAP 出库成本（表 3）：out_stock_amt_cb / total_outstock_qty
  ④ 缺失告警：0 + MISSING tag
```

### 2.4 BOM 商品单位成本链路

```
BOM 商品单位成本计算：

Step 1: 获取 parent（验收条码）的进货成本
        parent_unit_cost = parent 进货均价 或 parent 成本价

Step 2: 获取分摊比例
        分摊比例 = 出肉率(dressing_rate) × 成本比例(cost_rate)
        或按 sub 原价反推

Step 3: 计算 sub（销售条码）的单位成本
        sub_unit_cost = parent_unit_cost × 分摊比例
```

## 六、BOM 拆分的特殊处理

### 6.1 BOM 商品 vs 标品

**核心区别**：
- **标品**：验收条码 = 销售条码，进货时直接按 SKU 入库
- **BOM 商品**：验收条码 ≠ 销售条码，进货时按 parent 入库，销售时按 sub 出库

### 6.2 BOM 拆分对库存的影响

```
BOM 拆分场景：

进货时：
  parent（验收条码）入库 → 记录在 parent 的进货数量
  
拆分时：
  parent → sub（按出肉率拆分）
  parent 库存减少
  sub 库存增加
  
销售时：
  sub（销售条码）出库 → 记录在 sub 的销售数量
```

### 6.3 BOM 商品的单位成本计算

```
Step 1: 获取 parent 的进货成本
        parent_unit_cost = parent 进货均价

Step 2: 获取分摊比例
        ① 官方预拆数据：直接取 sub 的分摊金额/数量
        ② BOM 边定义：dressing_rate × cost_rate
        ③ 反推：按 sub 原价加权

Step 3: 计算 sub 的单位成本
        sub_unit_cost = 分摊金额 / 分摊数量
```

### 6.4 BOM 商品的库存方程

```
对于 sub（销售条码）：

期初数量 = 上日期末 sub 数量
进货数量 = 当日从 parent 拆入的 sub 数量（BOM 分摊）
加工入/出 = 正常加工转换
销售数量 = 当日 sub 销售数量
损耗数量 = 当日 sub 损耗数量
期末数量 = 当日 sub 盘点数量

未知损耗 = 库存方程反推
```

## 七、关键依赖关系

```
单位成本（effective_unit_cost）
    │
    ├─→ 进货额 = 进货数量 × 单位成本
    │
    ├─→ 加工额 = 加工数量 × 单位成本
    │
    ├─→ 库存额 = 库存数量 × 单位成本
    │
    └─→ 损耗额 = 损耗数量 × 单位成本

库存方程（数量侧）
    │
    ├─→ 期末数量 = 期初 + 进货 + 加工入 - 加工出 - 销售 - 已知损耗 - 未知损耗
    │
    └─→ 未知损耗数量 = 库存方程反推

金额侧
    │
    └─→ 所有金额 = 数量 × 单位成本（同一个单位成本）
```

## 九、总结

**核心发现**：

> **单位成本是整个链路的唯一关键变量。一旦确定单位成本，所有金额计算（进货、加工、库存、损耗）都只是"数量 × 单位成本"。**

**BOM 的作用**：

> **BOM 拆分只影响"进货数量"和"单位成本"两个维度：**
> - 进货数量：从 parent 级拆到 sub 级
> - 单位成本：从 parent 成本分摊到 sub 成本

**链路顺序**：

```
1. 确定单位成本（标品直接取 / BOM 分摊计算）
2. 获取各项数量（进货、加工、销售、损耗、库存）
3. 计算各项金额（数量 × 单位成本）
4. 库存方程计算期末数量
5. 反推未知损耗数量
6. 计算未知损耗金额
7. 汇总计算门店毛利
```
