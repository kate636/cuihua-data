## Block 5：猪肉多产出拆分

状态：源拆分金额与 `sale_recev_rate` 两级正式过账通过；共同单位第三级兜底待实现。

2026-07-08 至 2026-07-14 周测：483 条源边、33 个日期×parent、6 个活跃
parent、75 个 child。parent 转出总额与 child 流入总额均为 24,257.9998 元，
每日最大残差 `4.55e-13`。零价猪杂赠品保留数量，金额权重回退到
`sale_recev_rate`。单元测试 3/3 通过。

兜底规则已补入设计：若拆分金额和 `sale_recev_rate` 都不可用，只有部位数量已 100%
换算到共同库存单位时，才按标准重量分摊并令每个部位公共单位成本相同；否则隔离。
猪肉分类统一毛利率仅可作为报表展示分摊，不回写库存成本或 SKU 会计毛利。
当前代码尚未接入可信的 `normalized_child_qty`/单位覆盖 adapter，因此第三层暂不产生正式
过账；金额和比例都缺失时直接阻断。这是明确的待实现项，不是已完成能力。

## Block 7：matnr 身份快照

状态：通过。

2026-07-14 Foodmart 业务品类 87,832 条商品记录，84,548 条有 matnr。先应用 v1.5
分类映射后，得到 78,067 个唯一 matnr、78,224 个
`(matnr, report_category_code)` 身份组；157 个 matnr 跨报告品类。正式库存过账行数
为 0。matnr 只作身份/成本审计，策略固定为 `NO_POSTING`。

独立审查修复：

- Foodmart 配方快照补稳定 `relation_id=RECIPE|finished_article_id`，并增加
  `fetch -> resolve -> processing plan` 集成测试；
- 同一 BOM parent 中若存在“有数量但零源金额”的 child，全组改用
  `sale_recev_rate` 分配新滚动成本，避免零成本 child；
- parent 重构选择从整段 SKU 收紧为 `store + business_date + parent`，被隔离日期
  继续保留 purchase child 进货事实。
- 包装换码按门店和日期消费当天 article_convert，脏字符串、负数量、无限值和空主键
  直接阻断；
- matnr 禁止从原始分类 ID 拼接报告分类，调用前必须完成 v1.5 分类映射；
- 跨日滚动在注入首日进货前阻断“期初数量为 0、期初金额非 0”。
