# REVIEW-007: 差异矩阵根因下钻 — 负库存钉零透支成本泄漏 (FIX-019)

> **日期**: 2026-06-24 | **基于**: [REVIEW-006](REVIEW-006-next-fix-target.md)
> **范围**: 6/18–22 FM vs QDM (`strategy_fm_levels_result`, SKU 级, v2.3 重映射)
> **结论**: 定位并修复矩阵真正的最大驱动因素，总毛利差异 +18.9% → +6.3%

## 0. 前情提要：REVIEW-006 的方案已被否决

REVIEW-006 把下一个修复目标定为"BOM 父品利润强制归零"。该方案：

1. 已作为 **FIX-004** 实现（commit `e5f503c`），
2. 三次审查后写成旧 REVIEW-007（commit `86b7f3b`），
3. 随后**全部回滚**（`8a6030e` / `506bc9d` / `2db6a2a`）。

回滚原因：BOM 父品归零让总毛利差异变大，对分类×日期矩阵无改善。本质上 BOM 父子品的
利润分配差异是**可接受的口径差**（父品+/子品−符号相抵，品类级净额很小）。用户亦明确
"涉及 BOM 的 SKU 计算差异是正常的"。本次审查（复用 REVIEW-007 编号）转向矩阵的真正
驱动因素。

## 1. 全口径分解：差异不在销售/进货，在库存结转

6/18–22 五日，对两边应用相同 v2.3 重映射后逐品类分解：

| 维度 | FM vs QDM |
|------|------|
| 销售额 | **完全一致**（同源 sales_di） |
| 进货额 | **完全一致** |
| 期末库存估值（末−初） | 有差异，集中生鲜 |
| 未知损耗 | 有差异，集中生鲜 |

差异 100% 落在库存价值结转，不是销售或进货口径问题。这把搜索空间从"全链路"收敛到
"stock.py 的期末/损耗逻辑"。

## 2. 根因：负库存保护把透支成本"洗白"

非日清品 `eq < 0` 时，`stock.py` 走负库存保护：`end` 钉零、透支量 `-eq` 转 `unknow_lost`。
但毛利公式 `... + end − init` 不含 `unknow_lost`，期末又被钉高到 0 →
透支成本既不进 end 也不进利润 → **利润虚高**。QDM 允许负期末，自然把这部分扣进利润，
故 FM 在生鲜品类系统性高于 QDM。详见 [FIX-019](../fixes/FIX-019-negative-stock-clamp-cost.md)。

## 3. 修复与效果

`profit.py` 对 `dc='1' & eq<0 & end≈0 & unknow_qty>0` 精确扣回 `unknow_lost_amt`：

| 指标 | 修复前 | 修复后 |
|------|:---:|:---:|
| 总毛利差异 | +2,129 (+18.9%) | **+707 (+6.3%)** |
| 命中行 | — | 155 (dc='1') |
| 扣减额 | — | 1,422.54 |

烘焙(+201→+3)、冷藏乳品(+221→+12)、水饮(+13)、蛋(+51) 基本对齐。剩余热点（水产 +491、
牛羊 +383、熟食 −331）为生鲜 + BOM 子品跨日 euc 的结构性差异，属可接受范围。

## 5. 停在哪里

剩余差异是 FM 加权平均 euc 估值 与 QDM 估值法的结构性差异（生鲜 + BOM 子品跨日 euc）。
再收窄需逐 SKU 对齐 QDM 数字，缺乏可证伪的业务依据，故判定已达逻辑下限，不再追。
