## 1. 问题现象

FM vs QDM (`strategy_fm_levels_result`，SKU 级，v2.3 重映射) 6/18–22 五日对比，
总毛利 FM 比 QDM 高 **+2,129 元 (+18.9%)**。逐项分解发现：

- **销售额 FM = QDM**，每个品类完全一致（同源 `strategy_fm_sales_di`）。
- **进货额 FM = QDM**，完全一致。
- 全部差异集中在**期末库存估值（末−初）+ 未知损耗**两项，且高度集中在生鲜品类
  （蔬菜、水产、牛羊、禽、熟食）。

也就是说，差异不是销售或进货口径问题，而是**库存价值结转**的口径差。

## 2. 根因：负库存保护把"透支成本"藏起来了

`stock.py` 的库存方程：

```
eq = init + receive + bom_in - bom_out + compose_in - compose_out - sale - know_lost
```

对非日清品（`day_clear='1'`），当 `eq < 0`（卖出/损耗超过了可用库存，即"透支"）时，
走**负库存保护分支**：

```python
elif eq < 0:
    end_qty   = 0          # 期末钉零，不允许负库存
    unknow_qty = -eq       # 透支量记入未知损耗
```

期末被**钉高到 0**（本应是负数），透支量 `-eq` 转记到 `unknow_lost_qty`。

问题出在毛利公式：

```
profit = sale - receive - bom_in + bom_out - compose_in + compose_out + end - init
```

毛利只用 `end - init` 反映库存变化，**不直接减 `unknow_lost`**（设计上损耗应通过
end 下降体现）。但在钉零分支里，`end` 被人为抬高到 0，这部分透支成本：

- 没有进 `end`（被钉零了），
- 也没有进利润公式（公式不含 unknow_lost），

→ **凭空消失** → 利润虚高。

对比 QDM：QDM 允许期末为负，负的期末直接压低 `end - init`，自然把透支成本扣进了利润。
这正是两边在生鲜品类差异的来源——FM 把超卖/超损"洗白"了。

> 与 FIX-010（盘盈机制）的区别：FIX-010 处理的是 `unknow < 0`（盘盈）这一侧的结构性
> 差异；FIX-019 处理的是 `unknow > 0` 且 end 被钉零这一侧的**利润泄漏**，是逻辑漏洞而非
> 口径差异。

## 3. 方案：钉零分支精确扣回透支成本

在 `profit.py` 主毛利公式之后，对**精确命中钉零分支**的行扣回透支成本：

```python
clamp_mask = (
    (df['day_clear'] == '1')          # 仅非日清品
    & (df['eq_end_qty'] < -0.001)     # 库存方程为负（透支）
    & (df['end_stock_qty'] < 0.001)   # 期末被钉零
    & (df['unknow_lost_qty'] > 0.001) # 透支量为正（守卫，排除 is_counted 盘盈角落）
)
df.loc[clamp_mask, 'profit_amt'] -= df.loc[clamp_mask, 'unknow_lost_amt']
```

四个条件共同**精确定位** `stock.py` 的 `elif eq < 0` 分支，不误伤其它分支：

- **不碰日清品 `dc='0'`**：其 `unknow` 是软日清正常残差（含盘盈），属设计意图，扣了会双重惩罚。
- **不碰 is_counted 实盘分支**：`unknow_lost_qty > 0` 守卫排除"实盘=0 且 eq<0"角落
  （该角落 unknow 为负=盘盈，扣回会反向抬高利润）。
- **数据驱动**：扣减额用 FM 自己算出的 `unknow_lost_amt`（= 透支量 × euc），
  不引入任何外部速率或硬编码假设，也不试图"对齐 QDM 的数字"。

### 为什么不采用 REVIEW-006 的方案（BOM 父品利润归零）

REVIEW-006 把"下一个修复目标"定为 BOM 父品利润强制归零。该方案已作为 **FIX-004**
实现（commit `e5f503c`）并在三次审查（REVIEW-007，commit `86b7f3b`）后**全部回滚**
（`8a6030e` / `506bc9d` / `2db6a2a`）：它让总毛利差异变大、对分类×日期矩阵无改善，
且 BOM 父子品的利润分配差异属于**可接受的口径差**（父品+/子品−符号相抵，品类级净额很小）。
用户已明确：**涉及 BOM 的 SKU 计算差异是正常的**。FIX-019 因此转向矩阵的真正驱动因素
——生鲜库存结转，而非 BOM 父品归属。

## 6. 局限

剩余 +707 是 FM 加权平均 euc 估值法 与 QDM 估值法的**结构性差异**，集中在生鲜与
BOM 子品跨日 euc。继续收窄需要逐 SKU 对齐 QDM 数字，缺乏可证伪的业务依据，故停在此处。
