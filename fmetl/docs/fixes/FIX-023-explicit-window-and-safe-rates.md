# FIX-023：连续区间重刷与聚合比率安全除法

## 问题

v0.14 原命令固定发布最近7天。将结束日更新到2026-08-04会只保留2026-07-29至2026-08-04，
无法满足“删除7月27日前数据、保留7月27日起连续日账”的要求。9天聚合运行还暴露出一个浮点
尾差：损耗率分母业务上为0，汇总后残留约10的负14次方，除法产生超大比率并阻断落表。

## 处理

- `v014-shadow-week` 和 `v014-fetch-mirrors` 支持 `--start`。
- 显式区间额外抽取开始日前一日作为预热，发布区间内每天连续滚动期初和期末。
- `v014-compare-v15` 按影子库内的完整连续区间进行对比，支持 1 天或多天，日期断档时拒绝运行。
- 比率分母绝对值小于 `0.00005` 时按最终 `DECIMAL(18,4)` 精度视为0，比率记0。
- 非有限比率统一归零，禁止写入无穷值或超出字段精度的数值。

## 本地验证

- 来源范围：2026-07-26至2026-08-04；发布范围：2026-07-27至2026-08-04。

- 负期末库存0；数量和金额跨日断点均为0；8项硬门禁全部通过。
- 同日同SKU盘点重复组0。
- 单元测试155项通过。
