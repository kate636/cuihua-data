# v0.14 ETL 迭代周报
> 数据范围：A3XV，2026-07-24—2026-07-30。

## 核心改动
1. **商品关系统一登记**：同码、BOM、加工、包装换码分别处理；商品集 ID 用于识别商品身份，缺少转换数量或固定规则时进入待确认清单。
2. **加工量由 ETL 计算**：根据成品销售、报损、期初和期末库存计算加工产出，再按采购维护的加工比例扣减原料，门店无需填报加工量。
3. **库存和成本连续滚动**：D-1 仅作为启动种子；后续每日期初继承上日期末。有效盘点覆盖期末数量，期末金额按当日加权成本重算。
4. **问题记录不计入正式计算**：关系缺失、比例缺失、双码重复盘点、小数点错位、缺成本和原料不足不再计入未知损耗。
5. **输出和验证补齐**：保留 v1.5 的指标、维度和聚合语义，新增商品集层；客数按订单去重，比率按聚合后的分子和分母重算。
