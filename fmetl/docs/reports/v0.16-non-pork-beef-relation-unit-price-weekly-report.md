# v0.16 非猪牛转换关系单价计算过程

## 本次完成

- 核对 A3XV 2026-08-03 至 2026-08-04 数据。
- 排除猪肉、牛肉 BOM，将正式显式换码和加工关系的 SKU 合并为关系组；全部数量按公斤统一。
- 共识别 65 个关系组，其中 59 个两日有业务数据；38 个显式换码组、27 个加工组均具备公斤换算依据。
- 输出销售、期初、进货、损耗、期末、销售成本和门店毛利的金额、公斤数量及公斤单价，对比 v0.16 与生产永洪 v1.5。

## 对比结论

| 检查项 | 结果 | 判断 |
|---|---:|---|
| 销售额 | 两版均为 3,404.09 元 | 销售事实一致；有销售的 43 个关系组销售单价全部一致。 |
| 门店毛利 | v0.16 2,644.99 元；v1.5 305.86 元；差异 +2,339.13 元 | v0.16 毛利明显偏高。 |
| 期初单价 | 48/56 个可比组一致，匹配率 85.7% | 期初成本主体可用，少量组需核对跨日库存。 |
| 进货单价 | 23/23 个可比组一致，匹配率 100% | 验收金额和公斤换算正确。 |
| 期末单价 | 41/55 个可比组一致，匹配率 74.5% | 差异主要受内部转换和盘点承接影响。 |
| 损耗单价 | 5/19 个可比组一致，匹配率 26.3% | 两版损耗数量来源不同，需要分别核对盘点、报损和转换事件。 |
| 库存平衡差成本单价 | 14/43 个有销售组一致，匹配率 32.6% | 33 个关系组平衡差成本为 0，涉及销售额 1,987.68 元。 |

毛利差异集中在烘焙类 **+1,598.55 元（68.3%）**、熟食类 **+619.68 元（26.5%）**。33 个平衡差成本为 0 的关系组解释毛利差异 **1,634.08 元（69.9%）**。

## 原因判断

1. **关系登记已完成，内部转换记录没有生成。** 两日仅生成猪肉、牛肉 BOM拆分记录；非猪牛关系未生成 `PACK_CONVERT` 或 `PROCESSING` 计入每日库存和成本。
2. **显式换码缺转换数量依据。** 42 条固定关系未记录当日换码事件；现有算法在连续盘点依据不足时不能确认实际转换量。8 月 3 日、4 日分别存在 120 条、118 条验收码与销售码重复盘点记录。
3. **加工缺成品盘点。** 两日每天有 54 条加工记录缺成品盘点，无法根据期初、销售、报损和期末计算加工产出，原料成本没有转入成品。
4. **损耗计算规则不完全一致。** v0.16 按盘点和库存变化计算损耗；v1.5 的部分已知、未知损耗数量由损耗金额除以单价得到。损耗单价差异不能直接证明 v0.16 错误。

## 下一步

1. 采购将 42 条显式关系标记为“到货后 100% 全转”或“按实际事件转换”。全转关系按验收量生成内部转换记录；其余关系必须提供当日转换数量。
2. 为验收码、销售码指定唯一盘点承接码，消除双码重复盘点。
3. PDA 盘点范围补齐加工成品。关系、比例、期初、销售、报损和期末齐全后，ETL 再根据库存方程计算加工产出和原料转出。
4. 先重算毛利差异前 10 个关系组；验收内部转出入转出金额等于转入金额、销售成本大于 0、跨日库存连续后，再扩展到全部 65 个关系组。

## 数据边界

本次使用本地固定保存的 v0.16 两日库存和成本结果，以及只读 v1.5 参考表。结果只用于查找计算差异，v1.5 不作为绝对正确答案；本次未写入服务器或生产任务。
